# YT Downloader 🎬🎧

Сучасний, швидкий та зручний десктопний додаток для завантаження відео та аудіо з YouTube, побудований на базі **Tauri v2**, **Rust**, **React**, **TypeScript** та **yt-dlp**.

---

## ✨ Основні можливості

- **Формати завантаження:**
  - 🎬 **Відео:** MP4 (рекомендовано), MKV (підтримка всіх кодеків), WEBM.
  - 🎧 **Лише аудіо:** MP3 (320 kbps), M4A (оригінал без втрат), WAV, FLAC (lossless), OPUS.
- **Вибір якості:**
  - Доступні всі якості відео джерела (від 360p до 4K 60fps) з орієнтовним розрахунком розміру файлу.
  - Вибір мовної аудіодоріжки або об'єднання всіх доріжок в один MKV.
- **Зручне керування файлами:**
  - Автоматичне визначення системної папки `Downloads` — завантажуйте без зайвих кліків.
  - Швидке відкриття папки із завантаженим файлом у системному файловому менеджері.
  - **Розумне розв'язання конфліктів імен:** якщо файл уже існує, автоматично створюється нова копія з номером (`(1)`, `(2)`) або надається можливість перезаписати старий файл.
- **Швидкий та чуйний UX:**
  - Кнопка швидкої вставки з буфера обміну та автоматичне очищення сміттєвих трекінг-параметрів (`si=...`, `feature=...`).
  - Повністю асинхронна робота — інтерфейс не зависає під час аналізу чи завантаження.
  - Детальний прогрес: відсотки, швидкість, залишковий час (ETA) та поточний стан (завантаження, зведення FFmpeg, конвертація).
  - Можливість зупинити або скасувати завантаження в один клік.
- **Підтримка Cookies:** опціональна передача cookies з встановлених браузерів для завантаження приватних або 18+ відео.

## 🛠 Системні вимоги

Для роботи завантажувача у вашій системі мають бути встановлені:

1. **yt-dlp**
   - Arch Linux: `sudo pacman -S yt-dlp`
   - Ubuntu/Debian: `sudo apt install yt-dlp` або `pip install yt-dlp`
   - macOS: `brew install yt-dlp`
   - Windows: `winget install yt-dlp`
2. **ffmpeg** (необхідний для зведення відео/аудіо та конвертації)
   - Arch Linux: `sudo pacman -S ffmpeg`
   - Ubuntu/Debian: `sudo apt install ffmpeg`
   - macOS: `brew install ffmpeg`
   - Windows: `winget install ffmpeg`

## 🚀 Запуск у режимі розробки

1. Клонуйте репозиторій:
   ```bash
   git clone https://github.com/NotionMe/yt-downloads.git
   cd yt-downloads
   ```

2. Встановіть залежності:
   ```bash
   npm install
   ```

3. Запустіть додаток:
   ```bash
   npm run tauri dev
   ```

## 📦 Збірка релізу

Для збірки виконавчого файлу під вашу платформу:

```bash
npm run tauri build
```

Зібрані інсталятори та бінарні файли з'являться у директорії `src-tauri/target/release/bundle/`.
